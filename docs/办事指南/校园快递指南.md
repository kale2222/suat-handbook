# 校园快递指南

菜鸟驿站已经搬迁至开阳 1 号楼。寄件填地址、取件找驿站，这篇帮你快速分清新驿站、智能快递柜和超大件物流。

:::warning 不要再把旧址写成菜鸟驿站
原菜鸟驿站旧址已经改为智能快递柜。日常寄收快递请优先填写**开阳 1 号楼 `1F_19` 号**；急需取用的快件，可以选择投递至天璇楼 25 栋智能快递柜。
:::

## 应该选择哪个收货点

| 使用场景       | 推荐收货点         | 位置                     |
| -------------- | ------------------ | ------------------------ |
| 日常快递       | 菜鸟驿站           | 开阳 1 号楼 `1F_19` 号   |
| 急需取用的快件 | 智能快递柜         | 天璇楼 25 栋旧驿站位置   |
| 超大件物流货物 | 联系派件员送货上门 | 与派件员确认具体交付位置 |

## 日常快递地址

日常寄收快递请优先使用新菜鸟驿站地址。

```text title="新菜鸟驿站（推荐）"
广东省深圳市光明区新湖街道公常路1号深圳理工大学主校区开阳1号楼1F_19号
```

在购物平台中可以这样填写：

```text
收件人：填写本人姓名
手机号码：填写本人手机号码
所在地区：广东省深圳市光明区新湖街道
详细地址：公常路1号深圳理工大学主校区开阳1号楼1F_19号
```

新驿站位于开阳 1 号楼一层，在 5 号门对面、网球场旁。具体位置可以查看 [深理工地图](../深理工手册/深理工地图.md)。

## 智能快递柜地址

如果快件急需取用，可以选择投递至原驿站旧址的智能快递柜。

```text title="旧址智能快递柜"
广东省深圳市光明区新湖街道公常路1号深圳理工大学主校区天璇楼25栋智能快递柜
```

智能快递柜位于八分饱区域连廊下方、党群服务中心外部。填写地址时请明确标注“智能快递柜”，不要只写学校主校区。

## 超大件物流

超大件物流货物可以提前联系派件员，协商送货上门及具体交付位置。下单时建议保持手机畅通，避免派件员无法联系收件人。

## 取件与问题处理

- 收到取件通知后，请根据短信或平台提示确认快件被送往菜鸟驿站还是智能快递柜。
- 前往菜鸟驿站取件时，准备好取件码并按现场指引操作。
- 如果不小心拿错快递，请及时联系现场工作人员处理。
- 对驿站搬迁、快件存放或取件有疑问，可以致电 **[15989859867](tel:15989859867)**。

:::info 地址和营业安排可能调整
快递量较大或场地调整期间，驿站可能临时变更营业安排。具体以菜鸟驿站、快递公司和学校最新通知为准。
:::
