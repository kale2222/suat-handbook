# 书院及宿舍生活

## 书院生活

区别于传统大学，深理工的书院是同学们主要的生活单位：宿舍位于书院内，辅导师（其他高校通常称为辅导员）也归属于书院。

学校目前已有以下书院：

- 曙光书院
- 袁庚书院
- 先行书院
- 奋斗者书院
- 神舟书院

同学所属的书院由学校随机分配。

### 书院整体情况

1. **一楼主要是公共功能区。** 各书院的房间配置大致相同，但会有细微差别，通常包括宿管办公室、辅导师办公室、院长办公室、健身房、会议室、洗衣房、共享厨房、音乐坊、心理咨询室、体育设施、餐厅和库房等。
2. **学生宿舍位于书院楼的 2–5 层，均为四人间。**
3. **辅导师住在书院内。**
4. **楼层安排可能调整。** 目前男生主要住在 2、3、4 层，5 层主要是女生宿舍；具体安排会根据每年男女生人数灵活调整。
5. **生活问题可以找宿管。** 浴室地漏堵塞、床帘有虫子等大部分生活问题，都可以向宿管反映，建议直接在书院群内说明情况。
6. **公共设施的使用方式以各书院通知为准。** 可以参阅所在书院的新生指南（如有），或咨询书院老师和宿管。
7. **书院没有宵禁，也不强制统一熄灯。** 不过，仍需尊重室友的作息习惯。

想提前了解书院环境，可以前往 [校园地图](../深理工手册/深理工地图.md) 查看实景图，其中包含曙光书院与袁庚书院的部分基础设施。

## 宿舍整体情况

### 房间配置

- 本科生宿舍均为四人寝，采用上床下桌布局。宿舍的整体环境可以在 b 站搜到，条件非常好。
- 每间宿舍配有独立洗手台、淋浴间和马桶。
- 大部分情况下，两间宿舍共用一个阳台；也有一间宿舍单独使用一个阳台的情况。
- 水、电和网络全天供应。
- 每间宿舍配有一台空调和一个小吊扇，吊扇平时基本用不到。

### 学校提供的物品

每位同学通常配有以下物品：

- 床垫
- 床帘
- 写字白板
- 带插座的书桌（自带洞洞板）
- 椅子
- 大衣柜

在原有配置的基础上，学校新增了部分床上用品。目前统一配置通常包括：

- 床垫
- 床帘
- 被芯
- 枕芯

床单、被套和枕套不在统一配置范围内，需要自行准备，其余生活用品也需自行购置。

:::warning 具体物资以书院通知为准
不同年份、书院和宿舍楼的配置可能调整，请以所在书院发布的入住通知为准。本手册也会持续向老师确认并更新信息。
:::

## 宿舍生活注意事项

### 如何与室友相处

宿舍生活没有唯一标准，但提前沟通可以减少大部分矛盾：

1. **彼此尊重。** 遇到生活习惯不同的情况，先沟通再解决。
2. **了解室友的睡眠习惯。** 提前商量熄灯和安静时间。学校不强制熄灯，不代表可以忽视室友的正常休息。
3. **睡眠时间减少噪音。** 不要在室友睡觉时大声打字、聊天或制造其他噪音；确有需要时，可以到楼下共享空间。
4. **共同维护卫生。** 尤其注意卫生间、淋浴间和洗手台等公共区域的清洁。
5. **养宠物前先确认规定。** 必须遵守所在书院的相关制度，并提前与所有室友协商，日常也要及时清洁。
6. **提前安排值日。** 商量好清洁分工和值日时间，按时清理垃圾和公共区域。
7. **合理使用公共空间。** 不要长期占用公共区域，导致其他人的物品无处摆放。
8. **坦诚沟通共同开支。** 电费、空调使用等涉及集体费用，建议了解彼此的消费习惯和承受范围，提前约定规则。
9. **打游戏时控制音量。** 尽量不要影响室友，尤其不要在宿舍内大吼大叫。

### 丢失物品怎么办

1. **在书院丢失：** 书院失物招领处一般设在宿管办公室，可以先向宿管询问，也可以在书院群内发布失物信息。
2. **在教室丢失：** 可以前往教务办公室咨询。
3. **注意教室监控情况：** 为保护学生个人隐私，教室内没有监控，因此建议尽快回忆物品遗失的位置和时间，并及时寻找。
